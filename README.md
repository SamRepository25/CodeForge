## 📖 Overview

CodeForge is a full-stack developer platform that combines:

- 🌐 Personal Portfolio
- 📝 Technical Blog
- 🤖 AI-powered Developer Tools
- 🔐 Secure Authentication
- 👨‍💼 Admin Dashboard
- 📱 Responsive Modern UI

The project showcases modern full-stack web development using React, TypeScript, Supabase, and Tailwind CSS.

# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/SamRepository25/CodeForge.git
```

## Install

```bash
npm install
```

## Environment Variables

Create a `.env` file.

```env
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
```

## Run

```bash
npm run dev
```
