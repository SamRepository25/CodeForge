[ 01. OVERVIEW & PURPOSE ]

Lightweight Linux performance monitoring utility built to provide granular visibility into live host health, kernel task scheduling, memory consumption, and I/O bottlenecks without system overhead.

[ 02. SYSTEM IMPLEMENTATION ]

Interfaces directly with the Linux `/proc` and `/sys` virtual filesystems, capturing process states, thread hierarchies, load averages, and network socket statistics in real time.

[ 03. KEY FEATURES & CAPABILITIES ]

Dynamic terminal dashboard and web visualizer with interactive process filtering, signal dispatch (SIGTERM/SIGKILL), threshold alerting, and low-latency metrics collection.
